**Figma Make Prompt**

Design and generate a premium, interactive anniversary memory website celebrating a couple's one-year relationship anniversary.

The website should feel like a luxury digital scrapbook, cinematic memory book, and modern wedding website combined. The design must be elegant, timeless, emotional, and highly polished.

Avoid:

* AI-style gradients
* Purple and neon color schemes
* Glassmorphism
* Generic romantic templates
* Emoji-based decorations
* Cartoon-style UI
* Excessive shadows
* Cheap-looking animations

Use:

* Premium typography with elegant serif headings and refined sans-serif body text
* SVG illustrations and SVG icons only
* Warm neutral colors
* High-quality photography layouts
* Cinematic storytelling sections
* Smooth micro-interactions
* Magazine-style composition
* Large visual spacing
* Soft luxury aesthetic

Color Palette:

* Ivory #FAF7F2
* Warm White #FDFCF9
* Charcoal #222222
* Soft Gray #666666
* Deep Rose #A26769
* Champagne Gold #C6A972

### Loading Experience

Create a full-screen loading screen.

Center:

* Large romantic couple photograph
* Circular loading ring surrounding the image
* Floating SVG love particles orbiting around the image
* Percentage counter increasing from 0% to 100%

Animation:

* Soft glowing ring
* Floating celebration particles
* Gentle motion

When loading reaches 100%:

Display:
"One Year Of Us"

Subtext:
"A collection of memories, moments, and milestones."

Button:
"Enter Our Story"

Only after clicking Enter should the website reveal the main experience.

### Floating Celebration Effects

Across the entire website, create subtle floating animated decorations.

Use SVG elements such as:

* Hearts
* Roses
* Love letters
* Rings
* Sparkles
* Ribbon elements
* Tiny flowers
* Anniversary badges

Behavior:

* Float downward slowly
* Bounce gently when reaching page boundaries
* Drift naturally
* Move behind content
* Never block text or buttons
* Opacity between 10% and 30%
* Create a magical celebration atmosphere

These floating elements should continuously animate throughout the website experience.

### Technical Design Notes

* Desktop-first premium design with perfect mobile responsiveness
* Use SVG assets throughout
* Smooth Framer Motion-style animations
* High accessibility standards
* Apple-quality visual polish
