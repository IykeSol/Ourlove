# One Year Anniversary ❤️

A special interactive web experience built to celebrate our first year together. 

This project is a personal memory gallery and timeline, featuring:
- 🎵 Autoplaying background music (toggleable)
- 📸 A masonry grid Memory Gallery of our favorite moments together
- ⏳ A scrolling story timeline detailing how we met and grew
- ✨ Interactive animations and floating particles
- 📱 Fully responsive design for both desktop and mobile viewing

## Running Locally

To run this project on your own machine:

1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Clone or download this repository.
3. Open your terminal in the project folder and run:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser to the local address provided (usually `http://localhost:5173`).

## Building for Production

To create a production-ready build of the site:

```bash
npm run build
```

This will generate a `dist` folder containing the optimized website, which you can easily host on platforms like Vercel, Netlify, or GitHub Pages.
